# OTT Content Trend Analysis

## Project Overview
This project analyzes Netflix movies and TV shows using Python and SQL to identify patterns and trends in the available content.

The project focuses on exploring content types, genres, ratings, release years, production countries, and movie or TV show durations.

## Project Objectives
- Explore the distribution of movies and TV shows.
- Analyze content release-year trends.
- Examine content ratings and genres.
- Identify leading production countries.
- Explore movie and TV show durations.
- Present findings and content strategy recommendations.

## Tools & Technologies
- **Python** – Data analysis
- **Pandas** – Data cleaning and manipulation
- **Matplotlib & Seaborn** – Data visualization
- **SQL** – Data analysis queries
- **Jupyter Notebook** – Analysis environment

## Dataset
The project is designed to use the Netflix Movies and TV Shows dataset.

**Expected dataset filename:** `netflix_titles.csv`

Place the dataset in the project directory before running the notebook. The dataset is not included among the project files listed above.

## How to Run

1. Clone or download this repository.
2. Place `netflix_titles.csv` in the project directory.
3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

4. Open Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open `notebooks/OTT_Content_Trend_Analysis.ipynb` and run the notebook cells.
